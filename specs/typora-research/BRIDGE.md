# 已观测的 Typora 桥接字面量

2026-10-14 核验边界：当前副本 `appsrc/main.js`、`page-dist` 的 JavaScript 与 `html` 的 HTML，共 9 个文件。只匹配直接双引号的 `callHandler("...")`、`registerHandler("...")`、`callSync("...")`，不追踪动态拼接、别名或跨脚本注入。因此是已观测清单，不是所有运行 handler 的证明。

结果：98 个 callHandler 字面量、63 个 registerHandler 字面量、5 个 callSync 字面量。各位置的 UTF-8 byte offset 保存在 `/Volumes/external/Projects/typora-r/research/bridge-literals.json`。同名可能在多个文件重复出现，计数为去重后的 literal name 数量。

同步实现与服务分工见 [NATIVE.md](NATIVE.md)。Mdown 原生编辑器应采用 Swift 类型化服务，这份清单用于辨认职责，不要求实现 JS RPC 或照搬整个接口面。
